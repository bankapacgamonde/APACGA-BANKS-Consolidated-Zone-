## Standard Legitimization Protocol

Apply this protocol to any known, unknown, or newly introduced process:

1. **Documentation** — Write a clear SOP in Markdown.
2. **Risk Assessment** — Identify, rate, and document risks.
3. **Compliance Mapping** — Align with FATF, Basel, IFRS, local laws, OHADA, common law, and other applicable obligations.
4. **Pilot Testing** — Run a controlled 30-90 day pilot.
5. **Legal and Audit Review** — Obtain legal, compliance, and audit sign-off.
6. **System Integration** — Add audit trails, access controls, and operational logging.
7. **Staff Training** — Roll out training for accountable teams.
8. **Monitoring and Annual Review** — Monitor controls and refresh the process at least annually.
